# Landing Page - Lotuus Spa 🌿

Este es un sitio web desarrollado para un cliente del sector **Wellness/SPA**. El objetivo era crear un espacio donde los usuarios pudieran conocer los servicios y contactar directamente vía WhatsApp.

### 🛠️ Tecnologías usadas:
* **WordPress / Elementor** (Maquetación y estructura)
* **CSS Personalizado** (Ajustes de diseño y estilos específicos)
* **JavaScript** (Interactividad en la sección de servicios)

### 📈 Resultados:
* Diseño alineado con la identidad visual de la marca.
* Navegación intuitiva enfocada en la conversión (contacto directo).
