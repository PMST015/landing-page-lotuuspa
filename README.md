Landing Page para Lotuus Spa
Este es un sitio web desarrollado para un cliente del sector SPA, se requeria un espacio donde los usuarios pudieran ver que servicios ofrece la empresa, y por medio de un boton contactar por whatsapp con una asesora que les ayudara con el resto del proceso.

Tecnologías usadas:
* WordPress / Elementor
* CSS personalizado
* JavaScript para animaciones (seccion de servicios)

Resultados:
Se logro un diseño amigable con el usuario y que mostrara la identidad visual de la empresa.
